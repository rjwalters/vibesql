About This Data

This page shows performance trends for VibeSQL Embedded over time. Data is collected from automated benchmark runs stored in our dogfooding database.

  • TPC-H & TPC-DS: Decision support benchmarks measuring query execution time (lower is better)
  • TPC-C: OLTP benchmark measuring transactions per second (higher is better)
  • Sysbench: Micro-benchmarks measuring individual operation latency (lower is better)

Charts show the min (best), avg, and max (worst) performance for each run. Hover over data points to see commit hashes and exact values.
